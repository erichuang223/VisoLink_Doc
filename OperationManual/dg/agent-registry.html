Agent Registry 核准與解除

Agent 送出註冊後，要由 DG 管理員在 Agent Registry 核准才會開始收資料。核准、Online 與資料入庫是三件分開確認的事。

3.1

查看 Agent Registry

功能位置總覽頁最下方「Agent Registry」
前置條件與權限已登入 DG
TRUST / STATE
Pending（待核准）／Trusted（已核准），下方是 Online／Offline。
CONNECTIONS / WORKERS
這台 Agent 的設備連線數與背景工作數，含故障數。
OUTBOX
Agent 尚未送達的資料筆數。
REALTIME / BACKFILL
等待中的即時資料與補送資料。
LAST ACTIVITY／ERROR
最後一次活動時間與最近錯誤代碼。
  1. 開啟「總覽」，捲到最下方「Agent Registry」。
  2. 依需要在「操作」欄執行 3.2～3.4。

能判斷每台 Agent 是否已核准、是否在線、有沒有資料積壓。

失敗時先查
  • 清單是空的：Agent 端還沒啟用 DG 連線，或連不到 DG（Agent 手冊第 3 章）。
3.2

核准 Agent

功能位置Agent Registry ›「核准」
前置條件與權限DG 管理員；Agent 已在 Agent 端啟用 DG 連線
  1. Agent 端儲存並啟用 DG 連線後，總覽上方「PENDING TRUST」變成 1 以上。
  2. 在 Agent Registry 找到 TRUST 為 Pending 的那一列，按「核准」。
  3. 確認視窗「核准 Agent？」顯示 Agent 名稱與 ID，核對無誤後按「確認核准」。

畫面顯示「已核准 …；清單已更新。」，該列變成 Trusted；Agent 重新連線後顯示 Online。

核准只改變信任狀態，不代表 Agent 已 Online 或資料已入庫；請到「Tag 管理」與「Current Values」確認資料有進來。

失敗時先查
  • 顯示「此 Agent 已不在 Pending 狀態」：已被其他管理員處理，重新整理頁面。
  • 核准後一直 Offline：到 Agent 端「DG 連線設定」查看 Uplink 狀態與錯誤。
3.3

拒絕並刪除待核准的 Agent

功能位置Agent Registry ›「拒絕並刪除」（只在 Pending 列出現）
前置條件與權限DG 管理員
  1. 在 Pending 的那一列按「拒絕並刪除」。
  2. 確認視窗「拒絕並刪除待核准的 Agent？」說明待核准紀錄會從清單移除，按「拒絕並刪除」。

該 Agent 從清單消失。這台 Agent 之後若再連上，會重新出現在待核准。

失敗時先查
  • 不認得的 Agent 反覆出現：檢查 Enrollment token 是否外流，必要時請安裝人員更換。
3.4

解除離線 Agent 的註冊

功能位置Agent Registry ›「解除註冊」（只在 Trusted 且 Offline 的列出現）
前置條件與權限DG 管理員
  1. 確認要解除的 Agent 已離線（STATE 為 Offline）。
  2. 按該列的「解除註冊」。
  3. 確認視窗說明：歷史資料會保留；Agent 保留身分並把資料暫存在本機；DG 會收回這台 Agent 占用的授權權杖與點數。
  4. 按「確認解除註冊」。

該 Agent 不再列為 Trusted。Agent 端可「重新申請註冊」（DG 核准後補傳暫存資料），或「解除這個 DG」。

Tag 屬於 DG，解除註冊不會刪除 Tag 與歷史資料；Tag 會變成來源離線或無來源。

失敗時先查
  • 顯示「Agent 已恢復活動或不再為 Trusted」：Agent 又連上了，不能解除。
