運作中／維護中

維護中會暫停 DG 的資料接收、寫入、回寫、設定修改與查詢，用於還原或主機維護。Agent 的資料會暫存在 Agent 本機，切回運作中後自動補傳。

14.1

切到維護中與切回運作中

功能位置系統設定 › 系統概覽 ›「運作狀態」卡（備份與還原頁也有「到系統設定切換」）
前置條件與權限DG 管理員
  1. 開啟「系統設定」，在系統總覽找到「運作狀態」卡，按「切到維護中」。
  2. 確認視窗「切到維護中？」列出會暫停與仍可使用的功能，按「切到維護中」。
  3. 維護完成後，在同一張卡按「切回運作中」，確認視窗按「切回運作中」。

維護中時每一頁上方顯示「系統維護中」提示，總覽右上顯示「DG 維護中」；切回後恢復正常，Agent 暫存的資料自動補傳。

失敗時先查
  • Agent 與 VisoLink 不會跟著切換：需要時到各自的管理畫面切換（DG 不代切）。
14.2

維護中的影響

功能位置—
前置條件與權限—
暫停
接收 Agent 資料、寫入資料庫、回寫、設定修改、即時與歷史查詢。
仍可
登入、查看狀態、切換總開關。
Agent 端
資料留在 Agent 本機暫存（受 Agent 暫存上限限制），DG 切回運作中後自動補傳。
  1. 維護前先通知使用 VisoLink 即時畫面與回寫的人員。
  2. 維護時間較長時，確認 Agent 的暫存上限足夠（Agent 手冊第 8 章）。

維護期間資料不遺失，切回後依序補齊。

維護時間超過 Agent 暫存上限時，Agent 會刪除最舊的暫存資料。

失敗時先查
  • 切回後資料沒有補齊：看 Agent Registry 的 BACKFILL 欄，以及「系統設定 › 診斷與補送」是否暫停補送。
