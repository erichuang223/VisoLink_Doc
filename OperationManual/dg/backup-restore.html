備份與還原

手動備份 DG 的設定與 TagData（Tag 設定與歷史值），下載檔案自行保管；需要時上傳還原。定時備份、集中存放請用 VisoLink 備份中心。

12.1

建立設定備份

功能位置左側「系統設定 › 備份與還原」›「設定備份」
前置條件與權限DG 管理員
完整
全部九類。
快速設定
只含設定、不含紀錄。
自訂
逐項勾選；所需的相依資料會自動包含。
九類資料
帳號與登入設定、系統設定、安裝設定與憑證、Agent 註冊與信任、與 VL 的配對、保存目的端與密碼、歷史保存設定、回寫需求與紀錄、稽核紀錄。
  1. 選方式：完整、快速設定或自訂。
  2. 輸入備份密碼並再輸入一次。
  3. 按「建立並下載」，瀏覽器下載 .vlbk 備份檔。

取得加密的 .vlbk 檔；設定備份不含歷史值。

備份檔用這組密碼加密，DG 不保存密碼；忘記密碼就無法還原。授權（license）不在備份內。

失敗時先查
  • 「建立並下載」不能按：兩次密碼不一致或未填。
12.2

還原設定備份

功能位置備份與還原 › 設定備份 ›「還原」
前置條件與權限DG 管理員；DG 已切到維護中
  1. 先到「系統設定」把 DG 切到維護中（第 14 章），也請把連到這台 DG 的 Agent 與 VisoLink 切到維護中。
  2. 選擇備份檔（.vlbk），輸入備份密碼，按「檢查」。
  3. 檢查通過後按「還原」，在確認視窗核對要還原的類別與方式後確認。

DG 重新啟動，完成後頁面顯示每一類的還原結果；確認後切回運作中。

失敗時先查
  • 「還原」不能按：DG 還沒切到維護中。
  • 檢查失敗：密碼錯誤或檔案損壞。
12.3

備份 TagData 與 InfluxDB 資料

功能位置備份與還原 ›「TagData（歷史資料）」「InfluxDB（保存目的端）」
前置條件與權限DG 管理員
  1. TagData：整個 DG 資料庫（Tag 設定、保存分類與歷史值），以完整／差異備份。資料庫需掛有備份區，否則頁面會顯示不能做 TagData 備份。
  2. InfluxDB：每個位置一列；選位置、開始與結束日期（一次最多 7 天、一個檔），輸入備份密碼後按「建立並下載」。
  3. 還原 InfluxDB 時一次一個檔，多個檔請依日期先後逐一還原；同樣要先切到維護中。

取得歷史資料的備份檔，可在刪除資料或換機前保存。

TagData 還原會讓整個 DG 資料庫回到備份點，之後的資料會不見。

失敗時先查
  • 沒有 InfluxDB 列：尚未建立 InfluxDB 保存目的端（第 8 章）。
12.4

用 VisoLink 備份中心排程備份

功能位置VisoLink 備份中心（另一套系統）
前置條件與權限已安裝 VisoLink 備份中心
  1. 在 DG「系統設定 › API Token 管理」建立 Backup API Token（第 15 章），Agent 也在各自的「API Token 管理」建立。
  2. 在備份中心「受管主機」登錄這台 DG 與連線的 Agent，貼上各自的 Token。
  3. 設定排程，統一備份 DG 與 Agent。
  4. 需要時還原到原機，或在新機器上換機還原。

DG 與 Agent 依排程自動備份；換機後 Agent 不必改設定就會自動連回。

操作步驟請見 VisoLink 備份中心操作手冊。

失敗時先查
  • 換機後 Agent 沒連回：確認新 DG 的位址與憑證與原機一致。
