DataGateway 操作手冊

DataGateway（DG）負責接收 Agent 送來的設備資料、依保存政策寫入歷史資料庫，並提供即時值、歷史查詢與設備回寫。本手冊依 DG 管理畫面的左側選單分章。

14 個章節54 項操作功能對應系統：DataGateway／Agent 0.4.0-beta

第一次使用的順序

DG 與 Agent 分開安裝；資料由設備經 Agent 送到 DG，再保存與提供查詢。

  1. 連上 Agent
    在 Agent「DG 連線設定」填入 DG 的連線資訊並啟用，回到 DG「總覽」核准（第 2、3 章）。
  2. 建立資料點
    在 Agent 建立設備連線與 Tag；DG「Tag 管理」會自動出現對應的 Tag（第 7 章）。
  3. 設定保存
    在「歷史保存設定」調整額度、建立規則與分類並指派資料點；沒有保存政策的 Tag 不會保存（第 8 章）。
