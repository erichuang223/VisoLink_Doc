DataGateway Manual · CHAPTER 05

Data Flow Logs 資料流事件

Data Flow Logs 記錄每一批資料何時被 DG 接收、處理是否異常，協助追查「資料有沒有進來」。

5.1

查詢資料流事件

功能位置左側「Logs › Data Flow Logs」
前置條件與權限已登入 DG
S · Server 接收
DG 已接收這批資料；歷史是否入庫要另外確認。
D · 目的端寫入完成
資料已寫入保存目的端。
E · 處理異常
處理過程發生錯誤，看錯誤代碼與來源定位問題。
G · 紀錄缺口
部分事件未完整寫入 Log；不能直接判定測值遺失。
  1. 設定開始時間、結束時間（本地時間），或按「最近 15 分鐘」「最近 1 小時」「最近 24 小時」。
  2. 依需要選來源 Agent、來源連線、事件類型、處理結果（成功 OK／部分成功 PARTIAL／異常 ERR），或輸入錯誤代碼。
  3. 按「查詢事件」。

表格列出發生時間、來源 Agent／連線、事件、處理結果與筆數。

失敗時先查
  • 沒有任何 S 事件：Agent 沒有送資料，先看 Agent Registry 是否 Online（第 3 章）。
  • 大量 E 事件：記下錯誤代碼，再到「系統設定」與「歷史保存設定」檢查服務狀態。
5.2

追蹤識別碼與下載當日紀錄

功能位置Data Flow Logs › 事件列「識別碼與序號」
前置條件與權限已登入 DG
  1. 在事件列的「追蹤資訊」欄展開「識別碼與序號」，可看到 Agent ID、Connection ID、資料序號範圍與 Correlation ID。
  2. 需要提供給技術支援時，按「下載當日事件紀錄」，下載該 Agent／連線的 UTC 當日 Log。
  3. 要查較舊紀錄時，展開「進階來源篩選 · 以完整 ID 查詢舊紀錄」輸入完整 ID。

取得可交給技術支援的事件紀錄檔。

失敗時先查
  • 下載失敗：檔案可能已超過保存期間，改查較近日期。
