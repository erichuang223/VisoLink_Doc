前後台工作關係

後台準備資料與權限，前台將資料轉換成可監看、可分析的圖面。

  1. 後台準備
    建立資料來源、View、分類與使用權限。
  2. 前台製作
    在 Studio 建立圖面並完成資料綁定。
  3. 前台應用
    透過 Runtime 監看，並使用 Data Analysis 分析。
