CHAPTER 01

Dashboard 儀表板

管理者登入後可從同一個導覽進入身分、資料及系統功能，並從 Dashboard 掌握基本數量與近期操作結果。

1.1

登入後台

適用角色系統管理者
功能位置Admin 後台登入頁
操作前提有效管理帳號
  1. 開啟組織提供的 Admin 後台網址。
  2. 輸入管理帳號與密碼。
  3. 點選「登入」。
  4. 確認進入 Dashboard，右上角顯示目前使用者。

安全：不要在操作手冊、截圖或訊息中記錄密碼；登入失敗時先確認帳號狀態與輸入法。

1.2

認識後台導覽

左側依「身分管理、資料、系統」分組；上方顯示目前頁面、介面語系與登入者。

分組內容
身分管理使用者、群組、角色
資料資料來源、資料綁定、DataGateway 即時、資料權限、資料夾、媒體庫、圖庫管理
系統語系字典、授權管理、稽核紀錄、備份還原、API Token 管理、系統設定、快取管理
1.3

查看 Dashboard

功能位置儀表板
先看什麼異常數量與服務狀態
後續處理點卡片進入明細

儀表板最上方的「VisoLink 系統狀態」用一句話說明目前狀況（例如「有 1 件事需要處理」）與產品版本；下方依序是「需要處理」、「服務架構圖」，以及授權、資料來源與即時資料、畫面與綁定、帳號與權限、API Token、系統維護、最近活動等卡片。

區塊看什麼
需要處理依重要程度排列待辦（例如還沒有任何備份、字典有尚未翻譯的項目），點項目直接前往處理頁。
服務架構圖VisoLink Client、Admin、API 與 PostgreSQL、Redis、資料來源、DataGateway 之間的連線；綠線正常、紅線異常、虛線未設定。
授權目前點數、狀態與到期日，可點「前往」進授權管理。
資料來源與即時資料資料來源、已啟用、Views 數量，以及開啟本頁時測試的連線狀態。
系統維護運作中／維護中狀態與備份資訊。
先看摘要確認數量與狀態是否偏離平時
開啟明細由卡片進入對應管理清單
完成核對確認啟用狀態或異常項目
  1. 點選左側「儀表板」。
  2. 先看上方系統狀態與「需要處理」清單。
  3. 在「服務架構圖」確認是否有紅色（異常）的連線。
  4. 點卡片右上角「前往」或待辦項目，進入對應管理頁面處理。
  5. 需要最新狀態時點「重新整理」。

管理者可辨識主要資源數量，並由卡片直接進入處理。

1.4

查看近期稽核

儀表板下方的「最近活動」列出最新的稽核事件，包含時間、事件類型、資源類型與成功／失敗狀態。

  1. 捲動至「最近活動」。
  2. 先查看狀態是否為 OK 或 FAIL。
  3. 記錄異常事件類型與時間。
  4. 需要完整內容時，進入 Audit Logs 查看詳細資料。

已取得事件時間、事件類型與資源，足以在 Audit Logs 找到同一筆紀錄。
