CHAPTER 01

Dashboard 儀表板

管理者登入後可從同一個導覽進入身分、資料及系統功能，並從 Dashboard 掌握基本數量與近期操作結果。

1.1

登入後台

適用角色系統管理者
功能位置Admin 後台登入頁
操作前提有效管理帳號
  1. 開啟組織提供的 Admin 後台網址。
  2. 輸入管理帳號與密碼。
  3. 點選「登入」。
  4. 確認進入 Dashboard，右上角顯示目前使用者。

安全：不要在操作手冊、截圖或訊息中記錄密碼；登入失敗時先確認帳號狀態與輸入法。

1.2

認識後台導覽

左側依「身分管理、資料、系統」分組；上方顯示目前頁面、介面語系與登入者。

分組內容
身分管理Users、Groups、Roles
資料DataSource、DataBindings、Data Permissions、Folders、Media Library
系統Localization、License、Audit、Backup、API Token、System Settings、Cache
1.3

查看 Dashboard

功能位置儀表板
先看什麼異常數量與服務狀態
後續處理點卡片進入明細

Dashboard 顯示使用者、DataSource、啟用中的 DataSource、語系及近期稽核數量。

先看摘要確認數量與狀態是否偏離平時
開啟明細由卡片進入對應管理清單
完成核對確認啟用狀態或異常項目
  1. 點選左側「儀表板」。
  2. 查看各統計卡片的數量。
  3. 點選卡片可進入對應管理頁面。
  4. 若統計與預期不符，進入對應清單確認啟用狀態。

管理者可辨識主要資源數量，並由卡片直接進入處理。

1.4

查看近期稽核

Dashboard 下方列出最新 10 筆稽核事件，包含時間、事件類型、資源類型與成功／失敗狀態。

  1. 捲動至「最近稽核紀錄」。
  2. 先查看狀態是否為 OK 或 FAIL。
  3. 記錄異常事件類型與時間。
  4. 需要完整內容時，進入 Audit Logs 查看詳細資料。

已取得事件時間、事件類型與資源，足以在 Audit Logs 找到同一筆紀錄。
