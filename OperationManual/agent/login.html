登入與本機帳號

Agent 使用自己的本機管理帳號登入，與 VisoLink 帳號無關。忘記帳密時可用安裝時的救援帳號重設。

1.1

登入 Agent 管理畫面

功能位置瀏覽器開啟 Agent 管理網址（安裝時設定的連接埠，預設 5181）
前置條件與權限Agent 本機帳號
  1. 開啟 Agent 管理網址，畫面顯示「本機帳號登入」。
  2. 輸入帳號與密碼。
  3. 按「登入」。

進入 Agent「總覽」，右上角顯示「帳號 · 本機管理員」。

失敗時先查
  • 密碼錯誤或忘記帳密：用 1.2 部署救援登入重設。
1.2

首次設定登入與救援登入

功能位置Agent 登入頁「忘記帳密？使用部署救援登入」
前置條件與權限安裝時的初始或救援帳號
  1. 剛安裝、尚未建立本機帳號時，登入頁標題為「首次設定登入」，用安裝時的初始帳號登入。
  2. 已有本機帳號但忘記帳密時，按「忘記帳密？使用部署救援登入」，標題變成「部署救援登入」，輸入救援帳號與密碼後登入。
  3. 救援登入後左側只剩「總覽」「資訊診斷」與「帳號設定」，右上顯示「部署救援模式」；依第 10 章設定新的本機帳號與密碼。
  4. 登出後用新的本機帳號登入。

可用新的本機帳號正常登入並看到完整選單。

救援登入只能重設本機帳密，不能修改連線或其他設定。

失敗時先查
  • 救援帳號由安裝人員保管，手冊與畫面不會顯示。
1.3

登出與切換明暗主題

功能位置畫面右上角「登出」與明暗主題按鈕
前置條件與權限已登入
  1. 按右上角「登出」回到登入頁。
  2. 按半圓圖示切換明亮／深色主題。

登出後重新開啟任何頁面都要先登入。

失敗時先查
  • 共用電腦使用後務必登出。
