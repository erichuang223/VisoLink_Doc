DataGateway Agent 操作手冊

Agent 安裝在設備旁，負責從設備取得資料、推送到 DataGateway（DG）、接收 DG 轉來的回寫並寫入設備。本手冊依 Agent 管理畫面的左側選單分章。

13 個章節43 項操作功能對應系統：DataGateway／Agent 0.4.0-beta

第一次使用的順序

每台 Agent 有自己的本機帳號，不需要 VisoLink 帳號。

  1. 連上 DG
    在「DG 連線設定」填入 DG 位址、Token 與憑證並啟用，等 DG 管理員核准（第 3 章）。
  2. 建立設備連線
    在「Connections」新增 OPC UA 或 Modbus TCP 連線並建立 Tag（第 4～6 章）。
  3. 需要回寫時
    開啟連線的「回寫」，建立寫入安全規則並指定給可寫 Tag（第 7 章）。

選擇功能章節

章節順序：先登入，再依左側選單由上而下。Agent 只做資料的取得、推送、接收與回寫；保存政策與歷史查詢在 DG 設定。
