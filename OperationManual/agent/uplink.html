DG 連線設定

設定這台 Agent 要連到哪一台 DG。尚未啟用時 Agent 可獨立運作；保存並啟用後才向 DG 註冊，並需 DG 管理員核准。

3.1

設定並啟用 DG 連線

功能位置左側「DG 連線設定」
前置條件與權限已登入 Agent；已從 DG 總覽取得連線 URL、Enrollment token 與 DG 公開憑證
DG gRPC HTTPS 位址
DG 總覽「Agent 連線」卡的 AGENT 連線 URL，例如 https://<DG 位址>:7180。必須是所有 Agent 都連得到的固定名稱或 IPv4，且與憑證名稱相同；跨設備不可使用 localhost。
Site（可留空）
現場名稱，方便辨識。
Enrollment token
DG 總覽複製的註冊 Token；已保存時留空可沿用。
DG 公開憑證（PEM .crt）
DG 的公開憑證檔；畫面顯示目前憑證的 SHA-256 指紋供核對。
  1. 填入 DG gRPC HTTPS 位址與 Enrollment token，選擇 DG 公開憑證檔。
  2. 勾選「啟用 DG 連線」，按「儲存設定」。
  3. 確認視窗「啟用 DG 連線？」說明仍需 DG 管理員核准，按「啟用並註冊」。
  4. 畫面提示設定已保存、正在嘗試連線，請分別確認 Pending、Trusted 與 Online。

下方「註冊狀態」顯示已註冊、等待 DG 核准；DG 管理員核准後顯示「已註冊，DG 已核准」，Uplink 為 Online、信任狀態 Trusted。

安裝 Agent 時若已帶入 DG 位址、Token 與憑證，只要勾選「啟用 DG 連線」並儲存即可。

失敗時先查
  • Uplink 一直 Connecting：確認 Agent 主機能連到 DG 的 7180 埠，位址與憑證名稱相同。
  • 顯示 Token 被拒絕：重新從 DG 總覽複製 Enrollment token。
3.2

等待 DG 核准與重新申請註冊

功能位置DG 連線設定 › 註冊狀態；DG 總覽 › Agent Registry
前置條件與權限DG 管理員核准
  1. 請 DG 管理員到 DG「總覽 › Agent Registry」按「核准」（DG 手冊第 3 章）。
  2. 核准前，Agent「Connections」頁會顯示「已註冊、等待 DG 核准」，新增連線按鈕停用。
  3. 若 DG 端解除了這台 Agent 的註冊，Agent 會保留身分與暫存資料；在 DG 連線設定按「重新申請註冊」並確認，等 DG 再次核准後補傳暫存資料。

註冊狀態為「已註冊，DG 已核准」，可以新增設備連線。

失敗時先查
  • 核准後仍 Offline：看總覽的 Server Uplink 最近錯誤。
3.3

設定本機暫存保存上限

功能位置DG 連線設定 ›「本機暫存保存上限」
前置條件與權限已登入 Agent
最多保存時間
1 小時～30 天，預設 7 天，以資料採集時間計算。
最多保存容量
100 MB～50 GB，預設 2 GB。
  1. 輸入最多保存時間（天／小時）與最多保存容量（GB／MB）。
  2. 按「儲存暫存設定」。

立即生效，不需重新啟動；「暫存管理」頁顯示新的上限。

DG 正常時資料直接送出、不寫暫存；送不出去的資料才暫存在本機，DG 恢復後自動補送。超過任一上限時刪除最舊的待補送資料、保留最新資料，採集不會停止。

失敗時先查
  • 可用磁碟不足：到「暫存管理」看暫存所在磁碟的可用空間。
3.4

解除這個 DG（改連其他 DG）

功能位置DG 連線設定 ›「解除註冊」
前置條件與權限已登入 Agent
  1. 確認不再需要尚未送出的暫存資料。
  2. 在「解除註冊」區按「解除註冊」，確認視窗「解除這個 DG？」核對後確認。
  3. 之後可設定任何一台 DG 重新註冊（需該 DG 管理員核准）。

Agent 改回未註冊；本機的 DG 位址、註冊碼、信任憑證與位址鎖定被清除。

Agent 端解除註冊會刪除本機尚未送出的全部暫存資料，不會再送到 DG；重新註冊前採集的資料也不保存。

失敗時先查
  • 只是 DG 暫時離線時不要解除註冊；資料會暫存並在 DG 恢復後補送。
