Agent Manual · CHAPTER 12

備份與還原

備份 Agent 的設定（連線、Tag、規則等），不包含暫存的待送資料，也不會取代目前的 Agent 身分。

12.1

下載設定備份

功能位置左側「系統管理 › 備份與還原」›「建立一致性備份」
前置條件與權限已登入 Agent
  1. 按「下載設定備份」。

瀏覽器下載一個 ZIP 設定備份檔，請妥善保存。

失敗時先查
  • 下載失敗：確認 Agent 磁碟空間足夠。
12.2

安全還原設定

功能位置備份與還原 ›「驗證與安全還原」
前置條件與權限已登入 Agent；建議先切到維護中
  1. 按「選擇檔案」選擇設定備份檔。
  2. 勾選「我了解系統會先建立現況 safety backup，再套用此設定並重啟受影響 Worker。」
  3. 按「安全還原」。

系統先自動備份目前設定，再套用備份檔並重新啟動受影響的讀取工作。

損壞、遭修改或較新版本的備份會在覆蓋前被拒絕。跨機還原會保留目標機器的 Agent 身分；受機器保護的密碼類設定可能需要重新輸入。

失敗時先查
  • 還原被拒絕：確認備份檔完整，且不是來自較新版本的 Agent。
12.3

用 VisoLink 備份中心排程備份

功能位置VisoLink 備份中心（另一套系統）
前置條件與權限已安裝 VisoLink 備份中心
  1. 在備份中心登錄這台 Agent 所連的 DG 與 Agent。
  2. 設定排程統一備份；換機時在新機器還原。

換機還原後 Agent 不必改設定就會自動連回 DG；DG「點數使用狀況」中「等待還原」的權杖在還原後開始收集。

操作步驟請見 VisoLink 備份中心操作手冊。

失敗時先查
  • 換機後沒有連回：確認新機器能連到 DG 的 7180 埠。
