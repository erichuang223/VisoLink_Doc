# VisoLink 教育訓練完整課綱

## 一、課程架構原則

本訓練採「角色學習路徑 × 主題課程模組」設計：

- 三類受訓對象決定必修範圍、學習深度及實作標準。
- Course 00–06 是可獨立授課、重複選修及持續擴充的教材。
- 同一功能依角色採不同深度：使用者會操作、設計者會建構、管理員會配置與排查。
- 每門課均包含概念說明、介面導覽、操作示範、情境練習及課後驗收。

## 二、三類受訓對象與完成標準

### A. 全體人員與一般監看人員

學習目標：理解平台、正確選擇 Display、判讀時間與資料狀態，並使用 Runtime 分析功能完成回報。

必修課程：

1. Course 00｜VisoLink Overview
2. Course 01｜Runtime Operation

應具備能力：

- 分辨 Studio、Runtime、Administration。
- 找到工作所需 Display，確認目前是即時或歷史情境。
- 判斷資料載入、無資料、無權限及異常狀態。
- 使用全域時間 Filter、互動式時間窗與全畫面模式。
- 使用 Quick Trend 選擇並比較多個 Tag。
- 建立、保留、拖曳、排序及比較 Time Marker。
- 回報時保留人員、畫面、設備、時間與現象。

完成標準：可獨立完成一次指定監看任務、一次時間比較及一份可追溯的異常回報。

### B. Studio 畫面設計人員

學習目標：把操作需求轉成結構清楚、資料正確、可分析且可維護的 Display。

必修課程：

1. Course 00｜VisoLink Overview
2. Course 01｜Runtime Operation
3. Course 02｜Studio Basics
4. Course 03｜DataBinding and DataBrowser
5. Course 04｜Calculation and Variables

應具備能力：

- 建立、命名、分類及設定 Display 畫布。
- 操作選取、移動、縮放、對齊、複製、群組、鎖定及圖層順序。
- 依資訊目的選擇文字、圖形、Gauge、Trend 與操作類 Symbol。
- 從分類式 Data Browser 找到正確 DataSource、View、Tag 與欄位。
- 以拖曳方式建立元件並完成各類屬性的 DataBinding。
- 處理載入、無資料、無權限及資料型別不符狀態。
- 建立 Variable、跨來源計算、條件狀態與衍生 KPI。
- 在 Runtime 驗證時間範圍、不同權限、不同資料值與不同尺寸。

完成標準：由需求開始，獨立交付一張經監看人員操作驗收的 Display，且能說明每項資料與計算來源。

### C. 系統管理員

學習目標：以最小權限、可追溯變更及可回復原則，維持資料、人員與平台穩定運作。

必修課程：

1. Course 00｜VisoLink Overview
2. Course 01｜Runtime Operation（理解使用者情境）
3. Course 05｜DataSource Management
4. Course 06｜Admin and Governance

應具備能力：

- 建立及驗證 DataSource，判斷連線、權限、結構或資料更新問題。
- 建立 View、欄位映射與可供設計者理解的資料結構。
- 管理使用者生命週期與職責群組。
- 分別配置圖面權限與資料權限，使用實際角色驗證結果。
- 管理多語系術語與畫面顯示一致性。
- 理解 Cache 的資料緩衝、共用與多設備負荷分流角色。
- 查看 Cache 節點狀態、容量與負荷，採用最小影響範圍處理。
- 執行系統狀態判讀、備份回復演練、稽核及變更紀錄。

完成標準：可完成低風險日常管理；高影響變更前能提出影響評估、備份、回復及驗證方案。

## 三、Course 00｜VisoLink Overview

建議時間：30 分鐘。適用：所有人員。先備：無。

### 單元細節

1. 平台定位：資料連接、視覺設計、Runtime 監看、情境分析與治理。
2. 使用情境：中控大屏、操作工作站、日常巡檢、異常追查。
3. 三類角色：監看人員、Studio 設計人員、系統管理員的責任與交接。
4. 主要工作區：Studio、Runtime、Administration 的入口與用途。
5. 核心物件：DataSource、View、Tag、Field、Display、Symbol、DataBinding、Variable。
6. 完整流程：連接 → 整理 → 計算 → 設計 → 監看分析 → 治理。
7. 資料與時間：數值必須連同時間、設備、單位與比較基準判讀。
8. 雙層權限：圖面權限控制入口，資料權限控制內容。

驗收：學員能以自己的角色說明工作位於流程哪一段，以及需要與誰交接。

## 四、Course 01｜Runtime Operation

建議時間：60 分鐘。適用：監看人員必修；設計與管理人員理解使用情境。

### 單元細節

1. 登入與身分：正確環境、個人帳號、角色與可見範圍。
2. Display 導覽：分類、入口、畫面切換、重新載入與返回。
3. 畫面狀態：即時值、更新時間、載入中、無資料、無權限與錯誤。
4. 顯示模式：固定畫布、適應視窗及全畫面長時間監看。
5. 全域時間 Filter：即時、歷史、起訖時間與持續時間窗。
6. 時間同步：畫面元件與分析工具使用同一時間情境。
7. Data Analysis 入口：右下角標記數量、功能視窗與目前選擇。
8. Quick Trend：原 Popup Trend 能力、Tag 選擇、多序列與全畫面。
9. Time Marker：建立、保留、拖曳、排序、移除與比較。
10. 時間範圍彙整：加總、平均、最大、最小、筆數與圖表選擇。
11. 異常判讀：先確認時間與資料，再確認設備與比較基準。
12. 回報格式：畫面、設備、Tag、時間、現象、操作與影響範圍。

實作：指定 Display 中加入兩個 Tag、建立至少兩個 Time Marker、完成比較並回報。

## 五、Course 02｜Studio Basics

建議時間：90 分鐘。適用：Studio 設計人員。

### 單元細節

1. Studio 工作區：工具列、元件區、畫布、屬性面板、圖層與資料區。
2. Display 管理：建立、命名、分類、開啟、複製及縮圖。
3. 畫布設定：尺寸、背景、固定畫布、全畫面與目標顯示設備。
4. 基礎操作：選取、多選、移動、縮放、旋轉、複製、貼上與刪除。
5. 對齊與分布：網格、吸附、等距、成組及解除群組。
6. 圖層管理：前後順序、鎖定、顯示、隱藏及命名。
7. Symbol 類型：文字、形狀、圖片、Gauge、Trend、數值與互動控制。
8. 屬性設定：位置、尺寸、字型、顏色、邊框、透明度與狀態外觀。
9. 資訊設計：視覺層次、一致性、留白、單位與警示顏色。
10. 儲存與預覽：儲存時機、Runtime 預覽、不同尺寸與全畫面驗證。
11. 安全狀態：載入中、無資料、無權限與錯誤不可誤顯為正常值。
12. 交付流程：設計自檢、監看人員驗收、變更說明與回復方式。

實作：完成指定尺寸 Display，包含標題、設備狀態、三項 KPI、Gauge 與 Trend 區域。

## 六、Course 03｜DataBinding and DataBrowser

建議時間：90 分鐘。適用：Studio 設計人員。先備：Course 02。

### 單元細節

1. 資料層級：DataSource → View → Tag / Field 的關係。
2. 分類式瀏覽：依連接類型、設備、區域或業務用途縮小範圍。
3. 搜尋：使用名稱與關鍵字，辨認相似名稱的不同資料。
4. 資料型別：文字、數值、布林、日期時間與時間序列。
5. 資料中繼資訊：單位、更新頻率、時間欄位與資料責任人。
6. 拖曳建圖：從資料建立適合的預設 Symbol，再調整呈現方式。
7. DataBinding：文字、數值、顏色、可見性、狀態與趨勢序列。
8. 多筆資料：同一元件多屬性綁定及多序列比較。
9. 格式化：小數位數、單位、日期格式與空值顯示。
10. 權限結果：圖面可見但資料不可見時的元件行為。
11. 除錯：名稱、型別、時間、權限、資料更新與綁定路徑逐項確認。
12. 維護：資料結構異動時盤點受影響的 Display 與 Symbol。

實作：從 Data Browser 找到指定資料，以拖曳與手動設定完成數值、狀態及 Trend 三種綁定。

## 七、Course 04｜Calculation and Variables

建議時間：120 分鐘。適用：進階 Studio 設計人員。先備：Course 03。

### 單元細節

1. Variable 定位：重複使用的計算、轉換或中間結果。
2. 命名原則：用途、範圍、單位及資料責任可辨識。
3. 基礎運算：四則、比例、差值、百分比與單位轉換。
4. 條件邏輯：門檻、區間、布林判斷與狀態文字。
5. 跨來源計算：確認時間基準、更新頻率與缺值處理。
6. 衍生 KPI：將原始資料轉成效率、達成率、負載或品質指標。
7. 時間彙整：加總、平均、最大、最小及筆數的適用情境。
8. 套用 Symbol：數值、顏色、可見性、Gauge 與 Trend。
9. 邊界情境：除以零、空值、負值、極端值及過期資料。
10. 驗證方法：準備已知輸入與預期結果，逐項測試公式。
11. 可維護性：避免重複公式，保留商業定義與變更原因。
12. Runtime 驗證：切換時間、權限及資料狀態確認結果一致。

實作：以兩個來源建立衍生 KPI，配置三段狀態門檻並套用至數值、Gauge 與警示外觀。

## 八、Course 05｜DataSource Management

建議時間：120 分鐘。適用：資料與系統管理員。

### 單元細節

1. 建立前盤點：資料擁有者、用途、使用者、頻率、敏感度與影響範圍。
2. 連接類型：依關聯式、時序、工業資料或服務介面選擇適合方式。
3. 連線設定：端點、帳號、憑證與最小資料權限。
4. 連線測試：網路可達、驗證成功、來源回應與錯誤訊息。
5. View 建立：選取必要資料，建立清楚且穩定的使用介面。
6. 欄位映射：名稱、型別、單位、時間與原始欄位對應。
7. Tag 組織：依設備、區域及業務語意建立可瀏覽層級。
8. 資料預覽：樣本值、空值、時間排序、更新頻率及異常值。
9. 使用驗證：由 Studio 瀏覽、綁定，再於 Runtime 確認結果。
10. 異常判斷：區分連線、憑證、結構、權限、更新或來源問題。
11. 結構變更：先盤點依賴的 Display、Variable 與使用角色。
12. 停用流程：確認無使用依賴、通知負責人並保留變更紀錄。

實作：建立測試 DataSource 與 View，完成欄位映射、預覽及 Studio／Runtime 端到端驗證。

## 九、Course 06｜Admin and Governance

建議時間：150 分鐘。適用：系統管理員。先備：Course 05。

### 單元細節

1. 管理原則：最小權限、職責分離、變更可追溯、先驗證後擴大。
2. 使用者生命週期：建立、啟用、停用、到職、調職與離職。
3. 群組設計：依部門、職責、區域或工作情境管理，不逐人堆疊例外。
4. 圖面權限：控制 Display 的瀏覽、設計與管理入口。
5. 資料權限：控制 DataSource、View、Tag 與內容使用範圍。
6. 雙層驗證：使用實際角色帳號測試圖面與資料組合結果。
7. 多語系：術語、翻譯文字、識別碼、版面長度及 Runtime 抽查。
8. Cache 概念：資料暫存、共用、降低來源重複負荷及提升回應效率。
9. 負荷分流：Cache 可配置於多台設備，支援使用量與服務規模擴充。
10. Cache 狀態：節點可用性、容量、負荷、更新與資料一致性。
11. Cache 操作：先界定單一資料、來源、節點或整體範圍，再選擇性處理。
12. 系統狀態：從平台服務、資料管線及使用者情境三層判斷。
13. 稽核紀錄：時間、人員、環境、對象、操作、影響與結果。
14. 備份策略：範圍、週期、保存、權限、保留期限與責任人。
15. 回復演練：於受控環境定期驗證備份確實可用。
16. 變更流程：提出、評估、備份、執行、驗證、記錄及交接。
17. 異常處理：界定影響、保留證據、採取最小影響措施、驗證恢復。

實作：建立測試群組及雙層權限；判讀模擬 Cache／資料異常；完成一次變更、驗證與回復紀錄。

## 十、教材製作標準

每門 HTML 課程應包含：

1. 封面：課程編號、對象、時間與先備能力。
2. 學習目標：完成後可執行的任務，不只列功能名稱。
3. 概念頁：說明功能目的、使用時機與角色責任。
4. 介面頁：使用實際截圖並標示操作區域；尚無圖片時保留明確圖片位置。
5. 操作頁：依步驟說明前提、動作、預期結果與常見錯誤。
6. 情境頁：以監看、設計或管理工作的真實問題帶入。
7. 注意事項：權限、安全、資料狀態及高影響操作邊界。
8. 實作頁：提供目標、測試資料、操作任務及產出物。
9. 驗收頁：以可觀察結果判斷是否通過。
10. 講師備註：建議示範重點、常見問答及可延伸內容。
