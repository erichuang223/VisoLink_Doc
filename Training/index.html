VisoLink
教育訓練課程系列

三階段定義人員的學習路徑；九門課程承載可獨立授課、練習與驗收的完整知識模組。Course 00–06 對應 VisoLink 1.4.0-beta，Course 07 對應 DataGateway／Agent 0.4.0-beta，Course 08 對應備份中心 0.1.0。

階段 1｜全體人員00 產品家族概觀 → 01 Runtime 操作、分析與回寫
階段 2A｜一般監看人員00 → 01，完成監看、分析、手機檢視與異常回報實作
階段 2B｜Studio 設計人員00 → 01 → 02 → 03 → 04，完成一張含 RWD 版面的可運作 Display
階段 3A｜系統管理員00 → 01（理解）→ 05 → 06 → 08，完成資料、即時連線、權限、維運與備份中心實作
階段 3B｜資料整合與 OT 管理員00 → 07 → 05（DataGateway 即時與回寫），完成設備接入、保存政策、配對碼與回寫實作
COURSE 00｜共同必修

VisoLink 產品家族概觀

VisoLink、DataGateway、Agent 與備份中心的定位與搭配；時序資料先備觀念、四個工作區、核心名詞、操作角色與完整工作流程。

全體人員40 ＋ 15 分鐘先備章節VisoLink 1.4.0-beta／DataGateway・Agent 0.4.0-beta／備份中心 0.1.0
COURSE 01｜操作與分析

Runtime Operation

登入與保存登入、即時與歷史標示、手機與平板 RWD、班別一鍵切換、Quick Trend、Time Marker、設備回寫、網址參數與維護中畫面。

監看／設計／管理員75 分鐘
COURSE 02｜畫面設計

Studio Basics

從空白或 Display 樣本建立畫面；畫布、Symbol 與樣式、新圖庫與智慧圖形、Symbol 樣本、底板、RWD 版面與預覽。

Studio 設計人員120 分鐘
COURSE 03｜資料運用

DataBinding & DataBrowser

資料分類與搜尋、即時與歷史、拖曳套用、屬性綁定、替換 DataBinding、Display 匯出入與回寫表單設定。

Studio 設計人員120 分鐘
COURSE 04｜進階設計

Calculation & Variables

Variable、跨來源計算、衍生 KPI、條件邏輯與 Symbol 套用。

進階設計人員120 分鐘
COURSE 05｜資料管理

DataSource Management

關聯式資料庫引導式設定與 Oracle、VisoLink DataGateway 歷史、View 與 DataBinding、DataGateway 即時與配對碼、雙權限與回寫。

資料／系統管理員150 分鐘
COURSE 06｜系統治理

Admin & Governance

人員與權限、有效權限預覽、圖庫管理、Client 設定、多語系、Cache、授權裝置點數、運作中／維護中、備份還原與備份中心。

系統管理員180 分鐘
COURSE 07｜設備資料整合

DataGateway 與 Agent

Agent 接 Modbus TCP／OPC UA 設備、DataGateway 核准 Agent、Tag 管理與保存政策、即時與歷史查詢、配對碼交給 VisoLink、回寫與寫入安全規則、暫存與維護中、事件排查。

資料整合與 OT 管理員180 分鐘DataGateway／Agent 0.4.0-beta
COURSE 08｜備份與還原

備份中心（BackupCenter）

備份密碼、存放位置、登記受管主機、三種備份模式、手動備份與排程、備份紀錄、還原規則與事前檢查、原機／換機／局部還原、TagData。

系統管理員150 分鐘備份中心 0.1.0
