Runtime Data Analysis

從即時監看，到可操作的資料分析工作區

Data Analysis 將原有的 Popup Trend 與時間標記分析整合在同一個 Runtime 工作區。使用者不必離開監控情境，即可從「線」觀察趨勢，也能從「點」比較特定時刻的製程數值。

01

線的視角｜Quick Trend

原有 Popup Trend 已納入 Data Analysis。使用者可從 Runtime 累積加入多個資料標籤，在同一時間軸疊合趨勢線，觀察資料的方向、波動與關聯。

  • 不離開 Display 即可開啟趨勢檢視
  • 跨 Symbol 累積加入多個 Tag
  • 共用 Runtime 全域時間範圍
  • 適合快速確認變化走勢與相互關係
02

點的視角｜Time Marker Analysis

在 Trend 或 Table 中標記多個時間點，再選擇需要比較的資料標籤，把圖上的觀察轉換為可量化的數值分析。

  • 新增、拖曳、移除多個時間標記
  • 以任一時間標記設定比較基準
  • 比較原始值、差值、百分比、倍率與指數
  • 支援最近值、前值、後值、插值與精確時間對齊
同一個分析入口，兩種互補視角：先用趨勢線找出值得注意的變化，再用時間標記對準關鍵時刻，量化不同 Tag 在各時點的差異。

Security by Separation

圖面可以共享，資料仍然受到保護

VisoLink 將「能否開啟監控畫面」與「能否取得畫面中的工業資料」分開授權，避免共享 Display 時連帶開放敏感資料。

VISUAL ACCESS

圖面權限

控制使用者能否查看、編輯或管理 Folder 與 Display，決定監控畫面的可見範圍與維護能力。

FolderDisplay
DATA ACCESS

資料權限

控制使用者能否存取 DataSource、DataBinding 及查詢結果，依製程、產線與職責隔離底層資料。

DataSourceDataBindingQuery Result
安全降級：使用者能查看 Display、但沒有其中部分資料的權限時，系統保留畫面結構，受限制的位置顯示「權限不足」，不回傳實際數值。
