Why VisoLink

工業現場不缺數據，缺的是讓數據變成資訊的工具

現代工廠普遍已擁有大量資訊系統，每天持續產生海量數據。

PLC / DCS→ SCADA→ Historian / PI→ MES / ERP→ IoT / AI 分析

❗ 真正的問題

問題不是沒有數據，而是：數據分散在不同系統、不同格式，無法快速組合成現場需要的資訊畫面。改一張監控畫面，需要排工單、等廠商、等上線視窗，費時數週。

👷 最懂現場的人，反而最難改善現場

  • 製程工程師
  • 中控室工程師
  • 設備工程師
  • 生產主管

他們知道「要看什麼」，卻沒有工具可以自己動手。

✅ VisoLink 的解法

  • 直覺的自由畫布編輯器，學習曲線低，工程師自行操作
  • 連接現場已有的各類資料庫，不需重建資料架構
  • 修改畫面當場即時生效，不需重新部署或停機
  • IT 與 OT 各自關心的需求，同一平台全部涵蓋
  • Web-based，任何瀏覽器開啟，無需安裝 Client 端軟體

前端三大入口

Studio（工程師設計）

路徑：/displays、/editor
功能：建立與編輯 Display、設定 DataBinding

Runtime（操作員監看）

路徑：/runtime
功能：只讀即時監看、Popup Trend

Admin（系統管理員）

獨立部署 port 6002
功能：DataSource / 使用者 / 多語系管理

資料流程

① Admin 設定 DataSource（連線資訊 AES 加密儲存）
         ↓
② Studio 工程師建立 Display → 設定 DataBinding（DataSource → View → Fields）
         ↓
③ 儲存 DisplayJson（PostgreSQL jsonb）
         ↓
④ Runtime 載入 → RuntimeQueryScheduler 排程執行查詢
         ↓
⑤ IDataSourceDriver.QueryAsync → 外部 DB / PI Server / InfluxDB
         ↓
⑥ VisoDataFrame { Columns[], Rows[][] } → RuntimeDataStore
         ↓
⑦ Symbol 訂閱更新 → 畫面即時刷新

DataBinding 資料綁定系統

靈活的多層資料綁定架構

核心概念

Symbol
  └── DataBinding（可多個）
        ├── DataSource（連哪個 DB / API）
        ├── View（查哪張表 / 哪個查詢）
        ├── Fields（用哪些欄位）
        └── bindingType

一個 Symbol 可同時擁有多個 DataBinding，每個可連接不同 DataSource。

bindingType 類型

類型說明
tag_ref直接引用 PI Tag 名稱
af_refPI AF Attribute 絕對路徑
af_relative相對路徑（Collection Symbol 用，Phase 4）
querySQL / 查詢腳本，標準欄位映射

DataSource View

  • 每個 DataSource 可定義多個 View（查詢單元）
  • 每個欄位有：FieldName（真實名）、DisplayName（友善名）、Unit（工程單位）
  • View 預覽：「眼睛」按鈕，顯示前 5 筆資料確認查詢結果

Schema Browser（Admin）

  • 瀏覽資料庫完整結構（Table → Column 樹狀）
  • 點擊 Column 名稱 → 自動插入到 SQL 編輯器光標位置
  • 一鍵生成 SELECT * FROM TableName 模板
  • 適用：SQL Server / MySQL / PostgreSQL

Data Panel（Studio 左側）

  • 所有 DataBinding 樹狀清單，支援搜尋（Binding / Field / DisplayName / Calc 名稱）
  • 從 Data Panel 拖曳 Field 到畫布 Symbol，自動完成 Field Mapping
  • Field 下拉選單顯示：DisplayName（FieldName）[Unit]
計算引擎 Calculations

跨資料來源公式計算，產生虛擬欄位

Symbol 層級計算欄位，無需在資料庫或後端預先處理，直接在設定面板定義公式。

使用範例

Symbol DataBinding：
  DB1 = Pump_Flow    （每 1 分鐘）
  DB2 = Pump_Status  （每 5 分鐘）

Calculations：
  Calc.EfficiencyPct
    = DB1.FlowRate / DB1.MaxFlow * 100

  Calc.TempF
    = DB1.TempC * 1.8 + 32

  Calc.StatusLabel
    = IF(DB2.Status==1,"Running","Stopped")

Symbol valueField = Calc.EfficiencyPct

支援公式類型

類型功能
數學運算+ - * / ^、sqrt()、abs()、round()、floor()、ceil()
條件式IF(condition, true_val, false_val)，可巢狀
字串字串連接、substring()、format()
比較== != > >= < <=
邏輯AND、OR、NOT

跨來源時間對齊

  • 指定一個 Primary DataBinding 作為時間軸基準
  • 其他 DataBinding 以「最近已知值」（Last-Known-Value）對齊
  • 支援來自不同資料庫（如 InfluxDB + PostgreSQL）的欄位混合計算

RuntimeQueryScheduler

  • 根據全域時間範圍，對每個 DataBinding 呼叫對應 Connector
  • 回傳 VisoDataFrame（統一格式），Symbol 訂閱並更新渲染
  • 各 DataBinding 查詢獨立容錯，單一失敗不影響其他
  • easyPI Runtime Trend 查詢時間範圍同步跟隨全域 Filter
  • 趨勢圖可拖曳選取時間窗，快速聚焦特定製程時段
  • 增量查詢沿用既有資料，降低長時間監看的重複傳輸
Popup Trend

累積趨勢比較器 — 不離開監控畫面即可多點比對

操作流程

在 Runtime 對任意 Symbol 雙擊
  → 資料點加入「比較清單」
  → 自動開啟全螢幕趨勢圖

按「返回」→ 回到 Display，清單保留

再次雙擊另一 Symbol
  → 加入第二個資料點
  → Popup 顯示兩條趨勢線（累積）

按「清除」→ 清空清單，回到 Display

技術特性

  • 雙擊觸發，無需額外設定，所有 Symbol 自動支援
  • 同一資料點重複雙擊：略過，不重複加入
  • 時間範圍跟隨全域 Filter（調整時間同步影響比較圖）
  • 支援 LINE / POINT / BAR / AREA 四種模式切換
  • 可單獨移除清單中特定資料點
  • 僅 Runtime 模式有效；Editor 模式下雙擊無此效果

認證與安全機制

企業級安全設計，圖面與資料分層授權

🔐

JWT 認證

  • JWT（JSON Web Token）Bearer 認證
  • Refresh Token：長效 Token，Silent Renewal，不強迫重新登入
  • 登出即時 Revoke RefreshToken（伺服器端）
🔒

連線資訊加密

  • DataSource 密碼、API Key 以 ASP.NET Core DataProtection（AES-256） 加密
  • 加密後存入 PostgreSQL secure_config 欄位
  • 不以明文傳輸至前端
  • DataProtection Key 寫入 Docker Volume，跨容器重啟保留
📋

資料保護

  • Soft Delete：刪除操作設定 deleted_at，不實際移除資料
  • 完整 Audit Log：所有管理操作均記錄操作者、時間、變更內容
  • 顯示版本歷史快照（最近 5 版本，可查看或復原）

圖面與資料的雙層權限模型

VisoLink 將「能否開啟監控畫面」與「能否取得畫面中的工業資料」分開判斷，讓畫面可以共享，敏感資料仍依職責受到保護。

🖥️

圖面權限

控制使用者能否查看、編輯或管理 Folder 與 Display，決定監控畫面的可見範圍與維護能力。

安全降級：使用者可查看 Display、但缺少其中部分資料權限時，系統保留圖面結構，受限制的資料顯示「權限不足」，不洩漏實際數值。
授權層級管理對象保護目的
圖面層Folder / Display限制畫面瀏覽、編輯與管理範圍
資料層DataSource / DataBinding / Query Result隔離製程、產線與敏感工業資料
授權主體User / Group依帳號、群組與工作職責集中治理
Owner 轉讓、Copy Editor、全域角色與批次轉讓屬於後續權限治理擴充，不列入本頁現有功能範圍。
