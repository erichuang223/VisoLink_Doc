品牌意義現場挑戰為何 VisoLink產品價值核心能力建置方式治理導入
Industrial Data Visualization Platform

讓懂現場的人，直接把資料變成決策畫面

VisoLink 將既有工業資料、自由畫布設計、即時監看、情境分析與企業治理整合在同一個平台，縮短從需求到可用資訊的距離。

連接既有資料現場自主設計即時與歷史分析圖面與資料分層治理企業環境自行部署
The Meaning of VisoLink

以視覺化為入口，連結整合、感知與操作

VISO 代表四個產品核心；Link 不是第五個獨立能力，而是串聯四個核心的關鍵。

V — Visualize

視覺化：將設備、環境與營運資料轉化為直觀、易懂的資訊。

I — Integrate

整合：串聯不同系統、設備與資料來源，減少資訊孤島。

S — Sense

感知：即時掌握現場狀態與變化，支援人的感知與判斷。

O — Operate

操作：將洞察連結到實際的監控、操作與改善行動。

Visualize × Link × Integrate讓不同來源的工業資料，連結到視覺化呈現。
Visualize × Link × Sense讓設備狀態、即時數據與趨勢，連結到人的感知與判斷。
Visualize × Link × Operate讓視覺化不只是「看見」，更能連結到實際的監控與操作。
VisoLink讓視覺化，連結資料整合、現場感知與實際操作。
The Business Problem

工業現場不缺資料，缺的是快速組合資訊的能力

資料已經存在，但最後一哩的畫面經常仍依賴個別專案、跨單位排程與反覆客製。

◫

資料分散

製程、設備、能源與管理資料散落在不同系統，難以快速形成同一個判讀情境。

⌛

修改週期過長

最懂現場的人無法直接調整畫面，小變更也可能重新成為需求、開發與驗收專案。

◈

共享與保護難兼顧

企業希望擴大資訊使用，同時又必須依職責保護敏感製程資料。

Why Change Is Difficult
真正的瓶頸，不是沒有資料，也不是沒有開發能力；而是「最懂現場的人」與「真正能修改畫面的人」長期分離。
現場提出需求工程師知道要看什麼、如何判讀，卻無法直接落地。
技術資源翻譯需求在跨部門溝通中被拆解、排程並反覆確認。
每次重新交付畫面被當成單次成果，資料定義與設計難以持續重用。
變化再次發生製程、設備與管理需求一變，循環便重新開始。
VisoLink 的核心不是讓企業放棄治理，而是把日常畫面改善能力交還給現場，同時讓資料、權限、版本與維運仍然受到治理。
One Connected Workflow

讓資料到決策的六個步驟，在同一個平台中完整銜接

VisoLink 在既有資料系統與最終決策畫面之間，建立一條可以反覆使用、持續治理的工作流。

連接保留既有資料投資，接入關聯式、時序與工業資料服務。
整理把來源欄位整理成有名稱、型別、時間、單位與語意的資料入口。
計算不改動來源系統，也能建立差值、比例、條件與跨來源 KPI。
設計用自由畫布與工業元件，把現場知識轉成可閱讀的資訊結構。
監看分析在同一時間情境中看即時、歷史、趨勢、時間點與區間。
治理管理人員、圖面、資料、稽核、備份、授權、Cache 與生命週期。
降低重複建置畫面、資料綁定、計算與圖形持續重用
縮短需求週期具權限的設計者可直接驗證與調整
累積資訊資產交付成果留在平台，而不是散落在專案中
保持企業治理自主設計不等於繞過資料與維運責任
Studio & Data

工程師需要的設計自由，企業需要的可維護性

不重新打造資料孤島，而是把既有資料整理成可搜尋、可綁定、可計算及可重用的畫面資產。

01

自由畫布 Studio

以畫布、Symbol、圖層與屬性面板建立符合現場語意的監控畫面。

02

資料資產化

DataSource、View、欄位映射與 DataBinding 將來源資料整理成一致入口。

03

跨來源衍生指標

以 Variable 與 Calculation 建立效率、差值、比例、條件及其他業務指標。

04

可重用視覺元件

數值、趨勢、Gauge、Pie、Sankey、進度及工業圖形支援不同資訊問題。

Platform Capabilities

從「找到資料」到「可長期使用」，每一層都有明確產品能力

01

資料連接與整理

不是直接把查詢散落在每張圖上，而是由管理端建立 DataSource、View、欄位映射、預覽與 DataBinding。

  • 連線測試與啟停管理
  • 欄位名稱、型別、時間與單位
  • 分類式 Data Browser 與搜尋
  • 查詢結果與使用範圍治理
02

自由設計與重用

Studio 同時支援自由畫布、資料綁定與可重用圖形，讓設計不是一次性的圖片排版。

  • 畫布、物件、排列、圖層與復原
  • 數值、趨勢、Gauge、Bar、Pie、Sankey 等元件
  • 工業 Graphic Library
  • Display 複製、預覽與版本資產
03

時間情境與互動分析

Runtime 的所有元件與分析工具共享同一個時間情境，避免「畫面時間」與「分析時間」互相矛盾。

  • 即時與歷史全域時間 Filter
  • 互動式時間窗
  • Quick Trend 多點比較
  • Time Marker 與區間彙整
04

企業管理與規模化

當使用者、Display 與查詢量增加，平台仍需要身份、授權、稽核、備份與負荷管理。

  • Users、Groups、Roles
  • 圖面與資料雙層權限
  • Audit、Backup、License、API Token
  • Cache Server、TTL 與負荷分流
從畫面設計到企業治理，使用同一個平台持續累積

VisoLink 同時涵蓋 Display Library、Studio、Runtime 與 Administration，讓畫面、資料、分析與維運不再分散於不同工具。

Runtime Analysis

從即時監看，走向可操作的資料分析工作區

操作人員不用離開監控畫面，即可在同一時間情境下檢視趨勢、建立比較點並彙整指定區間。

Quick Trend

選擇多個資料點，以趨勢觀察變化方向與相互關係。

Time Marker

建立、保留、拖曳與比較時間點，讓事件前後差異可以追溯。

時間範圍彙整

針對選定期間計算加總、平均、最大、最小與筆數。

Why A Platform

VisoLink 的差異，不是「圖表更多」，而是改變交付與維護模式

比較面向一次性客製開發一般 Dashboard 工具VisoLink 平台化方式
畫面變更重新提出需求、開發與驗收可自行組合，但版面與工業語意可能受限具權限的現場設計者以自由畫布直接調整
資料使用查詢邏輯散落在個別專案連接器廣泛，但資料語意常由每張 Dashboard 各自處理DataSource → View → DataBinding 形成可治理資料資產
工業畫面高度客製，但重用與維護成本高以通用圖表和固定格線為主自由畫布、工業圖形與資料元件共同構成 Display
時間分析另行開發或切換其他工具依 Dashboard 與查詢個別設定全畫面、Quick Trend、Time Marker 共用時間情境
治理依每個專案自行處理多聚焦 Dashboard 分享權限圖面權限與資料權限分離，並整合稽核、備份與維運
成果累積專案結束後難以持續複製累積 Dashboard累積 Display、資料綁定、計算、圖形、權限與操作知識
Enterprise Governance

圖面可以共享，資料仍然受到保護

VisoLink 將畫面入口與底層資料的存取分開治理，並將日常管理、稽核、備份與系統狀態集中到管理後台。

圖面權限

控制 Folder 與 Display 的瀏覽、設計及管理範圍。

資料權限

控制 DataSource、DataBinding 與查詢結果的使用範圍。

管理與追蹤

集中處理使用者、群組、角色、多語系、授權與稽核。

維運與恢復

提供系統狀態、Cache、備份還原及 API Token 管理入口。

Where Value Appears

同一個平台，對不同角色解決不同的工作斷點

製程／設備工程師

把判讀經驗變成畫面

直接組合設備狀態、製程指標與趨勢，不必把每一次調整重新翻譯成開發需求。

中控／監看人員

在同一情境完成追查

IT／OT 管理者

讓自主不等於失控

集中管理資料入口、人員、權限、稽核、備份與平台狀態，降低影子系統。

生產主管／決策者
